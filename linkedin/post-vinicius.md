Fazer parte do desenvolvimento da plataforma da Rede Cuidar+ pela Solutech tem me ajudado a entender melhor como é trabalhar no desenvolvimento de uma aplicação de verdade.

No Front-end, estou trabalhando principalmente na construção da parte visual da plataforma, pensando em como apresentar as funcionalidades de uma maneira que facilite o uso no dia a dia das clínicas. Uma coisa que percebi durante o projeto é que uma interface não pode ser feita pensando somente na aparência, cada elemento precisa ter uma função e estar em um lugar que faça sentido.

Durante o desenvolvimento, também estou trabalhando com a estrutura das páginas, organização dos componentes e comportamento dos elementos da interface. Funcionalidades como os agendamentos precisam ser apresentadas de uma forma bem clara, porque o usuário precisa conseguir entender rapidamente o que está acontecendo na tela.

Outra questão que chamou minha atenção foi a adaptação da plataforma para diferentes dispositivos. Não basta a página funcionar apenas em uma resolução, então é necessario pensar em como os elementos vão se comportar em telas maiores e menores sem deixar a utilização confusa.

Esse projeto está sendo uma experiencia interessante para aplicar conhecimentos de HTML, CSS e JavaScript em uma situação mais próxima do que podemos encontrar no mercado. Também está me mostrando que o trabalho do Front-end tem bastante relação com as outras áreas, principalmente quando uma funcionalidade precisa sair da ideia e realmente virar parte do sistema.
